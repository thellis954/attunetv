# AttuneTV 0.5.3

Samsung Home 0.2.1 corrects the artwork problems reported on the QN65Q65FN. Netflix, Prime Video, Apple TV, Disney+, Hulu and YouTube use bundled service marks instead of tiny squares or generic Samsung placeholder icons. Other installed apps retain their own uncropped artwork, with color-matched mats when the TV permits image sampling. All-apps now has readable names, a neutral charcoal background and rounded white focus rings.

Favorites, pairing and actual app launch IDs are preserved. Logos work offline. Source/attribution is included in the package. Samsung's Home button still opens Smart Hub; app launching and paid AI behavior remain separate device acceptance checks.

Android is versioned 0.5.3/code14 for this coordinated release, with no launcher behavior change. All installers and setup guides reference the current downloads. Provider API use is billed separately from chat subscriptions.

Validation and physical-device findings are recorded in docs/device-checks/samsung-qn65q65fn.md. Public release publication requires passing Android tests/lint, service tests and browser flows. Browser previews are labeled separately from physical TV captures.
