# AttuneTV 0.4.2 — public preview

**A direct download for your Fire TV, with a consistent signing identity for future updates.**

Download **AttuneTV.apk** below. No GitHub account is required. Follow the [installation guide](https://github.com/thellis954/attunetv/blob/claude/blissful-hypatia-4dfwls/docs/install.md) for Mac, Windows or Linux; a computer is needed for setup, not everyday operation.

## Included

- Cinematic daily-photo Home, glass favorites dock, all-apps grid and app organization.
- Home search for installed apps and Amazon's movie/show search.
- Phone-based personalization, weather, calendar and ambient mode.
- Native ChatGPT setup/panel preview, with clearer button focus and simpler setup wording.
- Android-version guards for font and focus styling on older devices.
- A repeatable release workflow: build, unit tests, lint, signing, certificate/version checks, checksum and source metadata.

## Preview status

The launcher has been tested on an Insignia NS65-UQFL26 running Fire OS 8.1.6.4. Other devices need verification. This 0.4.2 package has build/test/signature validation; on-TV runtime testing of 0.4.2 remains pending.

ChatGPT account consent, a real answer and streaming playback behavior are still awaiting end-to-end device validation. The normal release **does not enable chat inside any streaming provider yet**. It does not capture video or audio. The launcher works without ChatGPT.

## Updating an existing installation

Use `adb install -r AttuneTV.apk` with your connected TV selected. The certificate matches the maintainer's locally installed 0.4.1 build. Other early development/CI APKs may have different certificates and cannot necessarily update in place. If Android reports a signature mismatch, stop and read the guide; uninstalling erases AttuneTV's settings and account connection.

The signing certificate is intentionally retained from the original local build for update compatibility. Its certificate name still says Android Debug; this distributed APK is a **non-debuggable release build**, signed with the pinned, protected key.

**Assets:** `AttuneTV.apk`, `SHA256SUMS.txt`, `release-info.json` (version, source commit, certificate fingerprint and test totals).
