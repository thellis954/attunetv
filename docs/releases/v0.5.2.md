# AttuneTV 0.5.2 — a Home for Samsung

Samsung **0.2.0** now opens to a cinematic Home: a bundled landscape, large clock, favorites dock, installed-app grid, app search and a direct Ask shortcut. Pin/unpin and reorder favorites using App options or Menu. Favorites and the app inventory stay on the TV. The existing phone pairing, provider setup and conversation are preserved.

**Samsung's remote Home button still opens Smart Hub.** This is Home inside AttuneTV, not a replacement for the TV's system launcher or an overlay over streaming apps. Add AttuneTV to Samsung's Home row for quick access. Search covers installed apps, not movie/show catalogs. The wallpaper is a fixed bundled photograph, not a daily feed. Some internal services are excluded; app launches depend on the TV's public APIs.

The coordinated bundle includes the signed Android **0.5.2 / code13 APK** (version update; Android behavior unchanged), configured unsigned Samsung **0.2.0 WGT**, guided Android installers, all setup guides, metadata and checksums. Samsung users must sign for their own TV; official APK users retain the same signing identity.

Automated checks cover remote navigation, scrolling, persistent favorites, app filtering, launch failures, phone pairing and shared context. The QN65Q65FN device checkpoint is documented separately. Browser test answers use fixtures. API usage requires your provider key and is billed separately from consumer chat subscriptions. No universal streaming-overlay or all-TV compatibility claim is made.
