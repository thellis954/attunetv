You’ll create an API key in your provider’s developer account. A normal chat subscription may not include API usage.

  1. Create an account and set a budget.

    Open your provider’s billing page. Add API credit if required and set the available spending controls. AttuneTV never buys credits for you.

    Open billing See pricing
  2. Create a key named “AttuneTV”.

    Use the provider’s API keys page. Give it permission to list models and generate text. Copy the new key, then return here.

    Open API keys
  3. Connect it here.

    The key is sent securely to this AttuneTV service and stored encrypted. It is never shown on the TV. Only pair with a TV and service you trust.

Model prices differ. Checking the key lists models; it does not generate a paid answer.

Resets at midnight UTC. This is a request limit, not a dollar cap. Failed or stopped requests may still cost money.
